# 02 - Simulink Fundamentals

This folder contains my **Simulink learning and practice work** as part of my MATLAB and Electrical Engineering learning journey.

The goal is to understand the basic Simulink environment and learn how to build, simulate, and analyze engineering systems.

---

## 🎯 Learning Objectives

- Understand the Simulink environment
- Learn how blocks work
- Build simple block diagrams
- Understand signal flow
- Run and analyze simulations
- Learn basic solver and simulation settings
- Prepare for Electrical Engineering system simulations

---

## 📚 Topics Covered

### 1. Basic Blocks

- Sources
- Sinks
- Gain
- Sum
- Product
- Integrator
- Scope

### 2. Signal Generation

- Constant signals
- Step signals
- Sine waves
- Repeating signals

### 3. Mathematical Operations

- Addition
- Subtraction
- Multiplication
- Gain
- Basic mathematical functions

### 4. Dynamic Systems

- Integrator
- Transfer Function
- State-Space basics

### 5. Simulation

- Start/Stop Time
- Solver settings
- Continuous vs discrete simulation
- Viewing results using Scope
