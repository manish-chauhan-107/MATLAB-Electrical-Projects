# 🧮 MATLAB Scientific Calculator

A menu-driven Scientific Calculator developed in MATLAB that performs common mathematical and scientific calculations. This project is designed to strengthen MATLAB programming fundamentals, modular programming, and function implementation.

---

## 📖 Project Overview

The Scientific Calculator provides a collection of mathematical operations frequently used in engineering and scientific computations. Each operation is implemented using separate MATLAB functions to maintain clean and reusable code.

## 🚀 How to Run

1. Open MATLAB.
2. Open the project folder.
3. Navigate to the `src` directory.
4. Run `main.m`.
5. Select the desired operation from the menu.
