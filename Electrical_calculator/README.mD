# ⚡ MATLAB Electrical Calculator

A menu-driven MATLAB application that performs basic electrical engineering calculations using standard electrical formulas.

---

## 📖 Project Overview

This project was developed to practice MATLAB programming concepts such as:

- Functions
- Switch-Case
- While Loops
- User Input
- Modular Programming
- MATLAB File Organization

The calculator provides multiple methods for calculating Voltage, Current, Resistance, Power, and Energy.

---

## ⚙️ Formulas Used

### Voltage

V = I × R

### Current

I = V / R

### Resistance

R = V / I

### Power

- P = V × I
- P = V² / R
- P = I² × R

### Energy

- E = P × t
- E = V × I × t
- E = I² × R × t
- E = V² / R × t

4. Run `main.m`.
5. Select the desired calculation from the menu.
